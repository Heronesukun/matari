# 函数与控制流程：先读懂代码在做什么

阅读一段数据结构代码时，不要从第一行开始逐字符翻译。先找三件事：**函数接收什么、可能返回什么、函数内部会修改什么。**

## 从左到右读一个函数

```c
bool insert(SqList *L, int pos, int value) {
    if (pos < 0 || pos > L->length) return false;
    // 执行插入
    return true;
}
```

可以拆成：

- `bool`：函数返回真假；
- `insert`：函数名，表示插入操作；
- `SqList *L`：接收一个顺序表的地址，函数可以修改这个表；
- `int pos`：插入位置；
- `int value`：要插入的值；
- `return false`：条件不满足，操作失败；
- `return true`：操作完成。

C 语言的参数本质上按值传递。这里传入的是“地址这个值”，所以函数通过 `L` 可以修改调用者持有的顺序表。

## 条件语句：先看失败分支

```c
if (L->length == MAX_SIZE) return false;
```

这类写法叫**提前返回**。阅读时先翻译为：

> 如果表已满，本次操作立即失败；只有没有返回时，后面的插入代码才会执行。

常见逻辑符号：

| 写法 | 含义 |
|---|---|
| `==` | 是否相等 |
| `!=` | 是否不等 |
| `<`, `<=`, `>`, `>=` | 大小关系 |
| `&&` | 两个条件都成立 |
| `||` | 至少一个条件成立 |
| `!condition` | 条件取反 |

不要把判断相等的 `==` 写成赋值的 `=`。

## 循环：只跟踪三个位置

```c
for (int i = 0; i < n; i++) {
    visit(a[i]);
}
```

读 `for` 时只看：

1. 初值：`i = 0`；
2. 继续条件：`i < n`；
3. 每轮变化：`i++`，也就是 `i = i + 1`。

因此访问的下标依次是 `0, 1, ..., n-1`。

常见变化方式：

```c
i++       // 每次加 1
i += 2    // 每次加 2
i *= 2    // 每次乘 2
i--       // 每次减 1
```

复杂度章节会重点利用这些变化方式判断循环次数。

## 这些函数名是不是语言自带的

| 名称 | 在 MATARI 中通常表示 | 是否一定是 C 标准函数 |
|---|---|---|
| `visit(x)` | 处理或输出元素 `x` | 否，常是占位操作 |
| `swap(a, b)` | 交换两个值 | 否，通常是辅助函数 |
| `min(a, b)` / `max(a, b)` | 取较小值或较大值 | 否，正文中的简写 |
| `push` / `pop` | 入栈与出栈 | 否，是栈的抽象操作 |
| `enqueue` / `dequeue` | 入队与出队 | 否，是队列的抽象操作 |
| `malloc` / `free` | 申请与释放动态内存 | 是，来自 C 标准库 |
| `sizeof` | 计算类型或对象占用字节数 | 不是函数，是运算符 |

看到陌生名称时，优先从上下文确认它的输入、返回值和状态变化。

## 一个完整的阅读示例

```c
int find_first(int a[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (a[i] == target) return i;
    }
    return -1;
}
```

先说结论，再看细节：

- 输入：数组 `a`、长度 `n`、目标值 `target`；
- 输出：第一次出现的位置；不存在时返回 `-1`；
- 状态：`i` 表示当前检查的位置；
- 停止：找到后提前返回，或检查完全部 `n` 个元素。

若 `a = [4, 7, 7]`，`target = 7`，函数在 `i = 1` 时返回，不会继续检查最后一个元素。

## 学到这里的最低标准

遮住解释后，你应该能读懂：

```c
bool is_empty(Stack *S) {
    return S->top == -1;
}
```

并说出：它接收一个栈的地址，只读取 `top`，当 `top == -1` 时返回真。
