# 计算机组成原理学习路线

计算机组成原理不是硬件名词清单。它研究的是：**程序中的数据和操作，如何被编码成位，并经过存储器、运算器和控制器完成执行。**

第一次上手时，若同时学习二进制、补码、浮点字段和 ALU，信息密度会过高。因此课程先增加一个位模式导入章节。

## 第一次进入请先选路线

### 对二进制不熟悉

```text
导入：位与运算的最小基础
→ 数据表示与运算
→ 存储系统
→ 指令与 CPU
```

先完成 [导入 · 位与运算的最小基础](/docs/cs/computer-organization/chapter-0)。它只补位编号、位权、固定宽度、逻辑运算和移位，不会提前要求掌握补码或浮点数。

### 已经熟悉二进制和位运算

先做 [导入自测](/docs/cs/computer-organization/chapter-0/readiness-check)。能够说明每一步理由后，可直接进入 [数据表示与运算](/docs/cs/computer-organization/chapter-2)。

## 推荐顺序

0. 导入：位、字节、位权、固定宽度、逻辑运算与移位；
1. 计算机系统概述：建立软件到硬件的层次视角；
2. 数据表示与运算：理解同一串位为何能表示不同值，以及硬件如何完成运算；
3. 存储系统：理解容量、速度和局部性的权衡；
4. 指令系统：理解机器能表达哪些基本操作；
5. CPU：理解取指、译码、执行与数据通路；
6. 总线：理解部件如何交换信息；
7. 输入输出：理解外设、接口、中断和 DMA。

## 每章分两轮学习

- **第一轮**：先建立位宽、解释规则、操作过程和结果检查的主干。
- **第二轮**：再补特殊值、硬件实现、边界情况和综合练习。

页面内容不是要求一次全部记住。每个已完成章节会在开头给出“首轮学习路线”。

## 自学时持续追问

- 当前讨论的是“数值”还是“保存数值的位模式”？
- 位宽是多少，解释规则是什么？
- 哪些状态由寄存器或标志位保存？
- 操作过程中数据经过哪些部件？
- 结果错误来自溢出、舍入、时序还是控制条件？

当前完整建设的核心章节是 [数据表示与运算](/docs/cs/computer-organization/chapter-2)。
