# 第三章 · 一元函数积分学

积分最容易出现“公式认识，但题不会下手”。这一章因此只抓三个核心能力：

1. **不定积分会选方法**：直接、换元、分部、部分分式不是并列背诵，而是根据结构选择。
2. **定积分先看结构**：对称、换元、变上限、反常都要先判型再计算。
3. **应用会建微元**：面积、体积、质量、功本质都是“一个小片贡献多少”。

## 学完本章应该形成的第一反应

- $g'(x)/g(x)$ → 想到 $\ln|g(x)|$；
- $f(g(x))g'(x)$ → 换元；
- 多项式 × 指数/三角 → 分部积分；
- 有理函数 → 先代数整理/部分分式；
- 对称区间 → 先查奇偶；
- 变上限积分求导 → 基本定理 + 链式法则；
- 变上限积分参与 $0/0$ 极限 → 考虑洛必达；
- 面积 → 先找交点和上下关系；
- 旋转体 → 先决定切片和旋转后的几何形状。

## 必会主干

- 原函数、不定积分与基本公式。
- 第一类换元、分部积分、简单部分分式。
- 第二类换元的典型结构。
- 定积分性质与牛顿—莱布尼茨。
- 定积分换元、分部。
- 变上限积分函数及其导数。
- 基本反常积分。
- 平面面积、旋转体体积和微元思想。

## 高频应用

- 换元与分部的组合。
- 定积分利用奇偶性和区间变换简化。
- 变上限积分 + 极限。
- 变上限积分 + 单调/极值。
- 面积需要分段。
- 旋转体中圆盘/垫片与柱壳的选择。
- 已知截面积求体积。

## 补充辨识

- 复杂三角有理式和冷门递推积分不作为入门主线。
- 弧长做到理解公式来源、会建式。
- 功、压力、质心等物理题重点学习微元建模，不追求大量刷题。

# 怎么用 MATARI 自学这一章？

### 第一轮：先练“看结构”

读 [不定积分与积分方法](/docs/math2/chapter-3/indefinite-integral) 时，每个例题开始前先停一下：

> “我现在看到的结构是什么？”

如果你总要看完解答才知道用换元还是分部，就继续复做标例，不要急着堆题量。

### 第二轮：把定积分和前两章连起来

[定积分、变上限积分与反常积分](/docs/math2/chapter-3/definite-integral) 重点不是多背几个性质，而是看清接口：

- 变上限积分求导 → 第二章链式法则；
- 变上限积分极限 → 第一章判型 + 第二章洛必达；
- 对称积分 → 第一章函数奇偶性；
- 反常积分 → 仍然回到极限。

如果这些连接能说出来，说明知识开始形成网络，而不是三章孤立记忆。

### 第三轮：应用题先建模，暂时不要急着积分

读 [定积分应用与综合题型](/docs/math2/chapter-3/applications) 时，可以故意只做到“写出积分式”再停。

如果积分式本身建立正确，后面的计算通常只是已学方法；如果积分式建立错了，算得再熟也没有意义。

### 第四轮：精选练习训练完整路线

[第三章精选练习](/docs/math2/chapter-3/practice) 中：

- A 组检查基本积分方法；
- B 组检查跨章节应用和建模；
- C 组只负责让你认识边界题型。

看详解时先对比**识别**和自己的第一步，再看计算过程。

## 什么时候算“前三章主干已经打通”？

至少做到：

- 一个常见不定积分能说明为什么选这个方法；
- 看到定积分先查区间和结构，不只会找原函数；
- 变上限积分能和求导、洛必达自然连接；
- 面积、体积题可以独立写出正确积分式；
- 知道极限、导数、积分不是三套独立技巧，而是会在综合题里互相调用。

到这里，前三章才算从“看过概念”进入“可以继续靠练习自我强化”的状态。
