# 使用说明

MATARI 不把知识压缩成只可背诵的结论，也不试图完整复刻教材。它要解决的是：**初学者如何从第一次接触，逐步走到能够独立完成典型应用。**

当前内容会明确区分“第一次需要掌握什么”和“之后再补什么”，避免一页内容被误认为必须一次全部记住。

## 一门新课从导入章节开始

计算机课程会使用代码、位模式和符号约定。若前置工具缺失，学习者很容易把语法困难误认为知识点困难。

因此每门课程先提供导入入口：

- [数据结构导入](/docs/cs/data-structure/chapter-0)：函数、循环、数组、指针、内存、递归和状态跟踪；
- [计算机组成原理导入](/docs/cs/computer-organization/chapter-0)：位、字节、位权、固定宽度、逻辑运算和移位。

已经掌握前置内容的学习者可以直接做导入自测，不必重复阅读。

## 每章采用两轮学习

### 第一轮：建立可用主干

只要求掌握：

1. 这个主题解决什么问题；
2. 当前对象和状态怎样表示；
3. 最基本的操作流程；
4. 边界和失败条件；
5. A 组必会练习。

### 第二轮：补完整性和迁移

主干稳定后再进入：

- 更严格的定义；
- 递归、均摊、特殊值等扩展内容；
- 多种实现的比较；
- B 组高频应用和 C 组补充辨识。

## 一页内容应该完成什么

每个重要主题尽量形成同一条学习闭环：

1. **导入与前置**：需要先认识哪些代码、符号或基础动作。
2. **问题入口**：这个概念解决什么问题，为什么现在需要它。
3. **识别信号**：题目或场景出现什么特征时应该想到它。
4. **最小理论**：只保留支撑应用所必需的定义、性质和条件。
5. **操作流程**：第一步做什么，下一步如何判断，什么时候停止。
6. **标例迁移**：不只展示答案，还解释选择方法的原因。
7. **易错边界**：哪些条件容易漏，哪些相似概念不能混用。
8. **精选练习**：按必会主干、高频应用、补充辨识分层，并提供逐题详解。

> 看懂不等于学会。遮住解答后，能够说出“为什么第一步这样做”，才说明知识开始变成自己的。
