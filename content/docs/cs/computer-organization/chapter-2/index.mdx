# 数据表示与运算

一串 `0` 和 `1` 本身没有固定意义。**位宽、编码规则和解释方式**共同决定它表示什么；运算部件只处理位，程序和指令负责赋予这些位具体含义。

学完本章，你应该能够：

- 在二、八、十六进制之间转换，并理解位权；
- 区分无符号数、原码、反码和补码；
- 在给定位宽下判断表示范围、符号扩展和截断结果；
- 完成补码加减并区分进位与溢出；
- 读写 IEEE 754 单精度浮点数的关键字段；
- 理解 ALU、加法器、移位器与状态标志的分工。

## 先建立一条总路线

遇到一道数据表示题，先按下面顺序确认：

1. **位宽是多少？** 8 位、16 位、32 位会直接决定范围和截断结果。
2. **按什么规则解释？** 同一位模式可被解释为无符号整数、补码整数、字符或浮点字段。
3. **当前做的是表示还是运算？** 先把操作数编码正确，再执行位运算。
4. **结果按什么类型判断？** 无符号看进位，带符号补码看溢出，两者不是一回事。
5. **是否发生扩展、舍入或截断？** 这些步骤可能改变数值或精度。
