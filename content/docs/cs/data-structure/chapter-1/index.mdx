# 复杂度：从代码看增长速度

复杂度不是给代码贴一个 `O(n)` 标签。它回答的是：**当输入规模变大时，时间或额外空间会以什么速度增长。**

学完这一页，你应该能够：

- 先说清楚输入规模 `n` 代表什么；
- 找到会随 `n` 重复的基本操作；
- 判断常数、线性、对数、平方和 `n log n` 级别；
- 区分时间复杂度与辅助空间复杂度；
- 知道最好、最坏和平均情况为什么可能不同。

## 先记住：复杂度比较的是增长，不是秒数

同一个算法在不同机器上运行时间不同，但当 `n` 从一千增长到一百万时，`O(n)` 与 `O(n^2)` 的差距仍会迅速拉开。

分析时通常忽略：

- 与 `n` 无关的常数倍；
- 低阶项；
- 具体机器指令耗时。

例如

```text
T(n) = 3n^2 + 10n + 7
```

当 `n` 足够大时，`n^2` 决定增长速度，因此记为 `Θ(n^2)`，也可以给出上界 `O(n^2)`。

## `O`、`Θ`、`Ω` 分别在说什么

- `O(g(n))`：增长速度的渐近上界，表示不会比这个量级更快地增长。
- `Ω(g(n))`：渐近下界。
- `Θ(g(n))`：上下界同阶，表示增长量级被确定下来。

在多数入门题里，题目说“求时间复杂度”通常希望得到紧确量级，因此应尽量写 `Θ(...)`；日常表达仍常用 `O(...)`。

## 常见增长顺序

从慢到快：

```text
1 < log n < n < n log n < n^2 < n^3 < 2^n < n!
```

这里的对数底数通常不影响渐近量级，因为不同底数只相差常数倍。

## 一套可执行的分析流程

拿到代码后按四步走：

1. **确定输入规模**：数组长度、节点数、矩阵边长，还是两个独立规模 `m` 与 `n`。
2. **找到基本操作**：比较、赋值、访问或递归调用中，哪一类次数随规模增长。
3. **计算执行次数**：看循环变量如何变化，内层循环是否依赖外层。
4. **保留最高增长项**：顺序结构相加取主项，嵌套结构通常相乘，但不要机械套用。

## 标例 1｜单循环为什么是线性

```c
for (int i = 0; i < n; i++) {
    sum += a[i];
}
```

循环体执行 `n` 次，每次做常数次操作，所以

```text
T(n) = c n + c0 = Θ(n)
```

**识别信号：**循环变量每次增加常数，边界与 `n` 成正比。

## 标例 2｜不是所有双循环都是 `n^2`

```c
for (int i = 1; i <= n; i *= 2) {
    visit(i);
}
```

`i` 依次为 `1, 2, 4, 8, ...`。执行 `k` 次后约有 `2^k > n`，因此 `k = Θ(log n)`。

**识别信号：**循环变量每次乘或除一个固定常数，通常是对数级。

## 标例 3｜三角形循环要把次数相加

```c
for (int i = 0; i < n; i++) {
    for (int j = 0; j <= i; j++) {
        count++;
    }
}
```

内层不是每次都执行 `n` 次，而是执行

```text
1 + 2 + ... + n = n(n + 1) / 2
```

所以仍然是 `Θ(n^2)`。

**复盘：**结论虽然和规则双循环相同，但理由不同。复杂度分析要说明执行次数，不能只数 `for` 的层数。

## 顺序、分支与嵌套怎么合并

### 顺序执行：相加后取主项

```c
scan_once(a, n);      // Θ(n)
scan_pairs(a, n);     // Θ(n^2)
```

总复杂度为 `Θ(n + n^2) = Θ(n^2)`。

### 分支：看所讨论的情况

```c
if (target == a[0]) return 0;
for (int i = 1; i < n; i++) {
    if (a[i] == target) return i;
}
```

- 最好情况：第一次就找到，`Θ(1)`；
- 最坏情况：最后找到或不存在，`Θ(n)`；
- 平均情况需要给出输入分布假设，不能凭感觉写。

### 嵌套：先看内层次数是否独立

若外层 `n` 次、每次内层固定 `n` 次，才可直接得到 `n × n`。若内层边界依赖 `i`，就要写求和式。

## 递归复杂度：先写“每次缩小多少”

### 每次只减少 1

```c
int f(int n) {
    if (n <= 1) return 1;
    return f(n - 1) + 1;
}
```

递推关系：

```text
T(n) = T(n - 1) + Θ(1)
```

递归深度为 `n`，所以时间 `Θ(n)`，调用栈辅助空间也是 `Θ(n)`。

### 每次减半

```c
int search(int a[], int left, int right, int x) {
    if (left > right) return -1;
    int mid = left + (right - left) / 2;
    if (a[mid] == x) return mid;
    if (a[mid] < x) return search(a, mid + 1, right, x);
    return search(a, left, mid - 1, x);
}
```

每次把问题规模缩为一半，递归深度是 `Θ(log n)`。

## 空间复杂度到底算什么

通常关注**额外空间**，不把输入本身占用的空间重复计算。

```c
int max_value(int a[], int n) {
    int ans = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > ans) ans = a[i];
    }
    return ans;
}
```

只使用固定数量变量，辅助空间 `Θ(1)`。

若复制一个长度为 `n` 的临时数组，则辅助空间 `Θ(n)`。递归还要计算调用栈深度。

## 高频判断表

| 代码特征 | 常见量级 | 先检查什么 |
|---|---:|---|
| 固定次数操作 | `Θ(1)` | 是否真的与输入规模无关 |
| `i++` 扫描到 `n` | `Θ(n)` | 是否提前退出 |
| `i *= 2` 或规模减半 | `Θ(log n)` | 起点与边界是否合理 |
| 两个独立完整循环嵌套 | `Θ(n^2)` | 内层是否依赖外层 |
| 每层做 `Θ(n)`，层数 `Θ(log n)` | `Θ(n log n)` | 每层总工作量是否确为 `n` |
| 穷举所有子集 | `Θ(2^n)` | 是否存在剪枝或状态复用 |

## 额外补充：均摊复杂度

动态数组扩容时，某一次复制可能需要 `Θ(n)`，但若容量按倍数增长，连续进行 `n` 次尾插的总复制次数仍是 `Θ(n)`，所以单次尾插的均摊复杂度是 `Θ(1)`。

均摊复杂度不是平均情况：它不需要假设输入概率，而是把一串操作的总代价分摊到每次操作。

## 常见错误

- 看到两层循环就直接写 `O(n^2)`；
- 把 `O(2n)` 当成比 `O(n)` 更高的量级；
- 忽略递归调用栈；
- 没说明 `n` 表示什么；
- 平均复杂度没有概率模型却随意取平均；
- 把实际运行时间和渐近复杂度混为一谈。

## 30 秒速查

```text
先定规模 → 找重复操作 → 算次数 → 取主项
加常数：线性
乘常数：对数
完整嵌套：通常相乘
依赖边界：写求和
递归：看规模缩减与分支数
空间：看临时结构和调用栈
```
