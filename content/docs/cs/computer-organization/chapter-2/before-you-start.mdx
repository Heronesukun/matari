# 开始前：数据表示与运算需要哪些位基础

这一章会同时出现进制、补码、标志位、浮点数和 ALU。第一次学习不应一次承担全部内容，先把阅读位模式的工具准备好。

## 最低前置检查

看到 8 位模式：

```text
10110110
```

你应该能够：

- 指出最右侧是第 0 位，最左侧是第 7 位；
- 按无符号位权读出数值；
- 每 4 位分组写成十六进制；
- 对两个模式执行 AND / OR / XOR；
- 说明逻辑左移或右移后哪些位被补入、哪些位被丢弃。

若还不稳定，先完成 [导入 · 位与运算的最小基础](/docs/cs/computer-organization/chapter-0)。

## 本章固定使用的答题抬头

每道题第一行先写：

```text
位宽：____ 位
解释规则：无符号 / 补码 / IEEE 754 / 其他字段
```

同一位模式在不同规则下可能表示不同值。脱离位宽和解释规则，结论通常不完整。

## 本章容易混淆的词

| 名称 | 先理解成什么 |
|---|---|
| 位模式 | 一串 0 和 1，本身不携带唯一数值类型 |
| 位宽 | 可保存多少个二进制位置 |
| 进位 `CF` | 主要服务无符号运算判断 |
| 溢出 `OF` | 主要服务补码有符号运算判断 |
| 截断 | 丢弃超出目标位宽的高位 |
| 舍入 | 浮点精度有限时选择一个邻近可表示值 |

## 热身

8 位模式 `11111111`：

- 作为无符号数是 255；
- 作为补码整数是 -1。

这不是两种不同的存储内容，而是对同一串位采用了不同解释。

理解这一点后，进入 [数据表示与运算总览](/docs/cs/computer-organization/chapter-2)。
