# 数学二

MATARI 不把教材重新抄一遍，而是把学习路径压缩成四层：

1. **先记住**：建立最小可用理解。
2. **标例**：看一个概念怎样真正落到题目里。
3. **题型地图**：只保留值得长期记住的常见考法。
4. **精选练习**：按必会、高频、补充三档刷题。

> 目标不是“内容越多越好”，而是让初学者在尽可能短的时间里形成可应用的知识框架，然后通过代表性题目把框架练实。

## 三档内容怎么用

| 层级 | 定位 | 学习策略 |
|---|---|---|
| 必会主干 | 缺了就无法继续往后学 | 第一次必须掌握并完成对应练习 |
| 高频应用 | 常作为题目主体或综合接口 | 主干稳定后重点刷 |
| 补充辨识 | 大纲内但相对低频/耗时 | 先做到看得懂、知道用什么方法 |

## 关于例题

例题不追求数量，而追求“迁移价值”。一个标例应该至少完成一件事：

- 展示一个稳定的解题流程；
- 暴露一个常见误区；
- 连接两个知识点；
- 让你以后看到相似结构时能迅速识别。

因此本站不会为每个概念堆十几道同质例题，而会把更多重复训练放到精选练习里。

## 关于刷题

练习题按常见度筛选，而不是把所有可能考法列全。高数前三章长期稳定的主线仍然是极限计算、导数计算与应用、积分计算与应用；历史分类资料也长期把这三章作为独立高频板块整理。本站会优先覆盖这些稳定题型，再把低频变式放到补充层。

第一次学习建议：**正文标例全部做懂 + 每章 A/B 组练习完成**。C 组用于时间充足时补齐边界。
