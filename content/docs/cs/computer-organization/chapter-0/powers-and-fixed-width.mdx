# 2 的幂、位权与固定宽度：理解范围和回绕

## 常用的 2 的幂

不需要一次背到很大，但下面这些会反复出现：

| 指数 | 数值 | 常见联系 |
|---:|---:|---|
| `2^0` | 1 | 最低位权重 |
| `2^1` | 2 |  |
| `2^2` | 4 |  |
| `2^3` | 8 |  |
| `2^4` | 16 | 1 个十六进制位有 16 种模式 |
| `2^8` | 256 | 1 字节有 256 种位模式 |
| `2^10` | 1024 | 容量计算中常见 |

## 二进制整数按位权相加

```text
10110₂
```

从右向左权重为：

```text
2^0, 2^1, 2^2, 2^3, 2^4
```

所以：

```text
10110₂ = 1×2^4 + 0×2^3 + 1×2^2 + 1×2^1 + 0×2^0
        = 16 + 4 + 2
        = 22₁₀
```

只有为 1 的位置贡献对应权重。

## 二进制小数使用负指数

```text
0.101₂ = 1×2^-1 + 0×2^-2 + 1×2^-3
        = 1/2 + 1/8
        = 0.625₁₀
```

浮点章节会继续使用这些负指数。

## 固定位宽意味着模式数量有限

`n` 位一共有 `2^n` 种不同模式。若按无符号整数解释，范围是：

```text
0 到 2^n - 1
```

例如 8 位无符号范围为 0 到 255。

这里先记住“模式有限”这个事实。补码如何把一部分模式解释为负数，会在正文展开。

## 前导零保持数值，但改变明确位宽

```text
101₂ = 0101₂ = 00000101₂
```

作为无符号数，它们数值相同；但最后一个写法明确表示 8 位。位宽明确后，范围、最高位和截断位置才明确。

## 超出位宽时只保留低位

8 位计算：

```text
11111111
+00000001
-----------
1 00000000
```

结果有 9 位，但存储位置只有 8 位，于是低 8 位为：

```text
00000000
```

这可以理解为模 `2^8` 运算，类似只有 0 到 255 的环形表盘。正文会进一步区分最高进位和有符号溢出。

## 截断与扩展是两种相反动作

- **扩展**：从较少位变为较多位，需要决定高位补 0 还是复制符号位；
- **截断**：从较多位变为较少位，直接丢弃高位，数值可能改变。

例如：

```text
16 位：00000001 00101101
截成 8 位：00101101
```

只保留低 8 位。

## 二进制科学记数形式

十进制有：

```text
6250 = 6.25 × 10^3
```

二进制同样可以写：

```text
101.11₂ = 1.0111₂ × 2^2
```

小数点向左移动 2 位，所以指数为 2。浮点数会把“符号、指数、有效数字”分别编码。
