# 使用说明

MATARI 不把知识压缩成只可背诵的结论，也不试图完整复刻教材。它要解决的是：**初学者如何在较短时间内，从第一次接触走到能够独立完成典型应用。**

## 一页内容应该完成什么

每个重要主题尽量形成同一条学习闭环：

1. **问题入口**：这个概念解决什么问题，为什么现在需要它。
2. **识别信号**：题目或场景出现什么特征时应该想到它。
3. **最小理论**：只保留支撑应用所必需的定义、性质和条件。
4. **操作流程**：第一步做什么，下一步如何判断，什么时候停止。
5. **标例迁移**：不只展示答案，还解释选择方法的原因。
6. **易错边界**：哪些条件容易漏，哪些相似概念不能混用。
7. **精选练习**：按必会主干、高频应用、补充辨识分层，并提供逐题详解。

> 看懂不等于学会。遮住解答后，能够说出“为什么第一步这样做”，才说明知识开始变成自己的。

- **数学二**：函数、极限与连续；一元函数微分学；一元函数积分学。
- **数据结构**：复杂度、线性表、栈与队列已进入完整建设；树、图、查找、排序等已搭好后续骨架。
- **计算机组成原理**：数据表示与运算已进入完整建设；存储系统、指令系统、CPU、总线与 I/O 已搭好后续骨架。
