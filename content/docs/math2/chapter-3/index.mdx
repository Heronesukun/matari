# 第三章 · 一元函数积分学

积分最容易陷入“公式很多、做题靠猜”。这一章只抓两件事：

1. **不定积分**：识别结构，选对换元或分部积分。
2. **定积分**：把积分当作累积量，熟练使用性质、变上限求导和几何建模。

> 学习标准：看到积分先判断“基本型 / 换元 / 分部 / 有理化处理 / 定积分性质 / 变上限 / 应用建模”，而不是无目的试公式。

## 必会主干

- 原函数、不定积分与基本公式。
- 第一、第二换元法。
- 分部积分法。
- 定积分性质与牛顿—莱布尼茨公式。
- 变上限积分函数及其导数。
- 定积分换元、分部积分。
- 反常积分的基本判定。
- 平面面积、旋转体体积。

## 高频应用

- 结构型不定积分：凑微分、整体换元、分部积分。
- 定积分利用奇偶性、周期性、区间变换简化。
- 变上限积分与导数/极限综合。
- 定积分与函数性质结合。
- 面积、体积的建模与分段积分。

## 补充辨识

- 三角有理式、简单无理函数积分保留典型方法，不做大量冷门技巧。
- 弧长、旋转曲面面积会建式即可，优先级低于面积和体积。
- 功、压力、质心等物理应用掌握“微元法”思想，作为扩展应用，不占主刷题量。
