# 栈与队列：限制操作位置形成行为模型

栈和队列仍然是线性结构，但它们故意限制了插入与删除的位置：

- **栈**：只在同一端进出，后进先出（LIFO）；
- **队列**：一端进入、另一端离开，先进先出（FIFO）。

这种限制不是缺点。它让数据处理顺序变得稳定，因此可以直接表达很多过程。

## 什么时候想到栈

题目出现以下信号时优先检查栈：

- 最近进入的对象要最先处理；
- 括号、嵌套结构、函数调用；
- 表达式求值与运算符暂存；
- 需要回退到上一个状态；
- 递归过程改写为显式结构。

## 什么时候想到队列

- 按到达顺序处理；
- 一层一层扩展状态；
- 广度优先搜索、树的层序遍历；
- 生产者与消费者之间缓冲；
- 任务排队与轮转。

## 学习时不要只背 LIFO/FIFO

你还需要明确：

1. 当前状态由哪些指针或下标表示；
2. 空与满如何判断；
3. 入栈、出栈、入队、出队分别先检查什么；
4. 数组实现中下标的约定；
5. 应用题中“压入什么、何时弹出”或“何时入队、何时扩展”。
