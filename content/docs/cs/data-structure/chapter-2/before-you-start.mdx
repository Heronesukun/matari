# 开始前：线性表需要哪些数组与指针基础

线性表同时使用数组和链表。若数组下标、对象字段或指针箭头还不稳定，正文中的“移动元素”和“修改链接”会混在一起。

## 最低前置检查

进入本章前，应能回答：

```c
SqList L;
SqList *p = &L;
```

- `L.length` 为什么使用点号；
- `p->length` 为什么使用箭头；
- 长度为 5 的数组为什么最后下标是 4；
- `NULL` 为什么不能当成普通节点访问；
- `malloc` 与 `free` 分别做什么。

不稳定时先看 [数组、结构体、指针与内存](/docs/cs/data-structure/chapter-0/arrays-pointers-memory)。

## 本章先固定两个层次

```text
线性表：逻辑结构
顺序表 / 链表：存储实现
```

题目说“在线性表第 `i` 个位置插入”时，先判断底层是数组还是链表：

- 顺序表需要移动元素；
- 链表需要找到前驱并修改指针。

## 第一次学习路线

### 第一轮

1. 阅读 [线性表总览](/docs/cs/data-structure/chapter-2)；
2. 学习 [顺序表](/docs/cs/data-structure/chapter-2/sequential-list)，重点只看下标、长度、插入与删除方向；
3. 学习 [链表](/docs/cs/data-structure/chapter-2/linked-list)，重点只看头结点、前驱和两条指针修改；
4. 完成 [线性表精选练习](/docs/cs/data-structure/chapter-2/practice) 的 A 组。

### 第二轮

再学习原地算法、链表反转、合并、双指针、缓存局部性和 [结构选择](/docs/cs/data-structure/chapter-2/compare)，随后完成 B、C 组。

## 本章常见名称

| 名称 | 含义 |
|---|---|
| `length` | 当前有效元素个数 |
| `MAX_SIZE` | 顺序表容量上限 |
| `pos` | 操作位置；页面会说明它采用 0 基还是 1 基 |
| `head` | 链表入口；可能指向首元节点，也可能指向头结点 |
| `p` / `q` | 临时节点指针，必须结合当前代码说明各自指向谁 |
| `malloc` | 创建动态节点所需内存 |
| `free` | 释放删除后的动态节点 |

## 热身：两种插入分别改变什么

顺序表插入：

```text
改变多个数组位置，再增加 length
```

链表在已知前驱后插入：

```text
新节点连接原后继，再让前驱连接新节点
```

能够把这两句话区分开，就可以进入 [线性表总览](/docs/cs/data-structure/chapter-2)。
