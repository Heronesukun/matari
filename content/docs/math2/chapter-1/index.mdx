# 第一章 · 函数、极限、连续

这一章不是为了背完定义，而是建立三个以后会反复调用的判断框架：

1. **函数**：先看定义域，再看结构和性质。
2. **极限**：先代入判型，再选方法。
3. **连续**：先看极限是否存在，再看是否等于函数值。

## 学完本章真正应该得到什么？

不是“我见过这些名词”，而是遇到题时能形成第一反应：

- 根式差极限 → 先考虑有理化；
- 标准小量乘除 → 等价无穷小；
- 两个近似量相减 → 警惕低阶抵消，考虑泰勒；
- 分段点 → 先算左右极限；
- 连续求参数 → 极限值必须等于函数值；
- 根存在 → 连续 + 零点定理。

## 必会主干

- 函数的定义域、复合、分段与基本性质。
- 函数极限与数列极限的基本语言。
- 左右极限与极限存在的关系。
- 无穷小、等价无穷小与无穷小阶。
- 两个重要极限、夹逼准则。
- 连续的判定、间断点分类、闭区间连续函数性质。

## 高频应用

- 复杂极限的结构拆解与方法选择。
- 分段函数参数确定。
- 等价无穷小、洛必达与泰勒的选择。
- 数列极限的夹逼思想。
- 利用介值定理/零点定理证明根的存在性。

## 补充辨识

- 严格的 $\varepsilon$–$\delta$ 定义用于理解极限含义，不作为第一次学习的计算主线。
- 反函数存在条件、隐函数概念以会辨认和正确使用为主。
- 抽象极限证明先建立直觉，主干稳定后再加深。

# 怎么用 MATARI 自学这一章？

建议不要连续把所有正文“读完”再做题。按下面循环：

### 第一步：读一个方法单元

先理解“什么时候用”和标例，不要求第一次就记住所有细节。

### 第二步：遮住解答复做标例

如果只觉得“看懂了”，但合上答案不知道第一步做什么，说明还没有学会。

### 第三步：用一句话说出识别信号

例如：

> “根式相减出现 $0/0$，先试有理化。”

能说出这种句子，比背一长串解答更重要。

### 第四步：做精选练习 A 组

A 组用于检查主干方法是否已经能独立使用。卡住时展开详解，重点看**识别**部分，而不只是答案。

### 第五步：B 组练方法选择

B 组会混合方法。目标是判断“为什么这里用这个，而不是另一个”。

C 组属于补充辨识，不应阻塞主线学习。

## 什么时候可以进入第二章？

至少做到：

- 定义域和函数性质题不再频繁漏条件；
- 常见极限能先判型再选方法，而不是随机试公式；
- 能解释等价无穷小为什么不能在加减中机械替换；
- 分段点会主动看左右极限；
- 知道连续与零点定理可以解决什么问题。

不要求第一章所有难题都做完再前进。先建立稳定主干，后面学到洛必达、泰勒和积分以后，还会回来反复强化极限。
