# 开始前：栈与队列需要哪些状态基础

栈与队列的定义很短，但实现题高度依赖状态约定。第一次学习前，先把“操作名”和“状态变量”分开。

## 抽象操作不是语言内置函数

```text
push(x)      把 x 放到栈顶
pop()        删除并返回栈顶
peek()       读取栈顶但不删除
enqueue(x)   把 x 放到队尾
dequeue()    删除并返回队头
```

这些名字描述数据结构行为。具体实现可以使用数组，也可以使用链表。

## 本章必须先看清变量约定

### 顺序栈

正文常采用：

```text
top 指向当前栈顶元素
空栈：top = -1
```

于是入栈通常先增加 `top` 再写入，出栈先读取再减少 `top`。

### 循环队列

正文采用：

```text
front 指向队头元素
rear 指向下一可写位置
```

并使用：

```c
rear = (rear + 1) % M;
```

让下标在数组末尾后回到 0。若取模还不熟，先看 [状态跟踪、递归与取模](/docs/cs/data-structure/chapter-0/trace-recursion-modulo)。

## 每道操作序列题都画状态

例如空栈执行：

```text
push(5), push(7), pop(), push(9)
```

状态写成：

```text
[] → [5] → [5, 7] → [5] → [5, 9]
```

不要只在脑中模拟。循环队列题则至少写出每一步的 `front`、`rear` 和有效元素。

## 进入正文前的三个问题

- `peek` 与 `pop` 的区别是什么？
- `front == rear` 在本文约定下表示什么？
- `(7 + 1) % 8` 为什么等于 0？

能准确回答后，进入 [栈与队列总览](/docs/cs/data-structure/chapter-3)。
