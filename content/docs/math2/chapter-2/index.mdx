# 第二章 · 一元函数微分学

这一章真正要建立两层能力：

1. **会求导**：面对显函数、复合、隐函数、参数方程能选对求导方法。
2. **会用导数解决问题**：单调、极值、不等式、根、最优化、渐近线都能回到导数和极限。

如果只做到“求导公式会背”，只完成了这一章的一半。

## 学完本章应该形成的第一反应

- 分段点可导 → 先连续，再左右导数；
- 函数多层嵌套 → 拆层用链式法则；
- 底数和指数都含变量 → 对数求导；
- $0/0$ 或 $\infty/\infty$ 且求导变简单 → 洛必达；
- 低阶项抵消、比较无穷小阶 → 泰勒；
- 证明不等式 → 构造差函数；
- 证明唯一根 → 存在性 + 单调性；
- 求最值 → 建函数、写范围、再求导。

## 必会主干

- 导数定义、左右导数、可导与连续。
- 基本求导、链式法则、隐函数、对数求导、参数方程。
- 微分和线性近似。
- 罗尔、拉格朗日中值定理的实际使用。
- 洛必达法则的入口和变形。
- 泰勒展开与“展开到够用的阶”。
- 单调、极值、最值、凹向上/凹向下、拐点、渐近线。

## 高频应用

- 分段函数连续/可导求参数。
- 洛必达与泰勒求极限，以及二者选择。
- 中值定理证明等式或不等式。
- 构造函数证明不等式。
- 连续 + 单调证明根唯一。
- 函数图像与根的个数。
- 实际最优化建模。

## 补充辨识

- 柯西中值定理掌握使用方向，不必第一次就深挖证明。
- 复杂高阶导数、曲率等放在主干稳定以后。
- 技巧性极强的辅助函数构造不作为入门阶段主刷题量。

# 怎么用 MATARI 自学这一章？

### 第一轮：把“求导方法选择”练稳

读 [导数、微分与求导法则](/docs/math2/chapter-2/derivative) 时，不只复做计算，还要能解释：为什么这题用链式、隐函数或对数求导。

如果基本求导还经常错，先不要急着大量做复杂应用，因为后面的符号判断都会建立在导数正确的前提上。

### 第二轮：专门练“极限工具选择”

学习 [中值定理、洛必达与泰勒](/docs/math2/chapter-2/mean-value-and-lhopital) 时，重点比较：

- 为什么某题满足洛必达入口；
- 为什么有些结构必须先变形；
- 为什么发生抵消时泰勒更自然；
- 同一道题两种方法都能做时，哪种更短、更能解释结构。

### 第三轮：把导数用到真正的问题里

[导数的应用](/docs/math2/chapter-2/applications) 是本章最不能略读的一页。

读完每个例子后遮住解答，先说出自己的路线：

> “这题是唯一根，所以先证明存在，再证明单调。”

这种“路线语言”是以后独立做题的核心。

### 第四轮：精选练习完成迁移

[第二章精选练习](/docs/math2/chapter-2/practice) 中：

- A 组检查基本技能；
- B 组检查会不会把工具用于证明、根、图像、最值；
- C 组只补边界，不应拖住主线。

## 本章学习顺序

1. [导数、微分与求导法则](/docs/math2/chapter-2/derivative)
2. [中值定理、洛必达与泰勒](/docs/math2/chapter-2/mean-value-and-lhopital)
3. [导数的应用](/docs/math2/chapter-2/applications)
4. [第二章精选练习](/docs/math2/chapter-2/practice)

## 什么时候可以进入第三章？

至少做到：

- 常见函数求导能稳定完成；
- 能说清洛必达的直接入口只有哪些不定式；
- 知道什么时候泰勒比洛必达更适合；
- 会用导数证明一个简单不等式；
- 会完整证明“方程有唯一根”；
- 会把一个简单现实最值问题化成单变量函数。

不必等所有复杂证明题都熟练。第三章的变上限积分会再次调用导数和洛必达，跨章节回练本身就是学习过程的一部分。
