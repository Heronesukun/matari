# 栈与队列的典型应用

真正掌握栈与队列，不是会写 `push` 和 `enqueue`，而是看到处理顺序时能够选择正确模型。

## 应用 1｜括号匹配：未闭合的最近左括号先处理

扫描表达式：

1. 遇到左括号，压栈；
2. 遇到右括号，若栈空则失败；
3. 检查栈顶左括号是否与当前右括号匹配；
4. 匹配则弹栈，否则失败；
5. 扫描结束后栈必须为空。

```c
bool match(char s[]) {
    Stack st;
    init(&st);

    for (int i = 0; s[i] != '\0'; i++) {
        if (is_left(s[i])) push(&st, s[i]);
        else if (is_right(s[i])) {
            if (empty(&st)) return false;
            char left = pop_value(&st);
            if (!pair(left, s[i])) return false;
        }
    }
    return empty(&st);
}
```

**为什么是栈：**右括号必须先匹配最近还没闭合的左括号，正好是后进先出。

## 应用 2｜后缀表达式求值

后缀表达式 `3 4 + 2 *`：

1. 读到数字 3、4，依次压栈；
2. 读到 `+`，弹出右操作数 4 和左操作数 3，计算 7 后压回；
3. 读到 2，压栈；
4. 读到 `*`，弹出 2 和 7，得到 14。

注意非交换运算的弹出顺序：

```text
right = pop()
left  = pop()
result = left operator right
```

## 应用 3｜中缀转后缀的核心判断

扫描中缀表达式时：

- 操作数直接输出；
- 左括号压栈；
- 右括号弹出直到左括号；
- 运算符到来时，弹出栈顶中优先级更高或按结合性应先计算的运算符，再压入当前运算符；
- 扫描结束后弹出剩余运算符。

不要一开始死记完整规则。先理解运算符栈是在**暂存尚不能确定输出时机的运算符**。

## 应用 4｜层序遍历与广度优先：先发现先扩展

队列适合保存“已经发现但尚未处理”的节点：

```text
起点入队
while 队列非空：
    取出队头节点
    处理它
    把尚未访问的相邻节点依次入队
```

树的层序遍历和图的广度优先搜索都使用这个模式。

**为什么是队列：**同一层更早发现的节点应更早扩展，保持先进先出才能逐层推进。

## 应用 5｜递归与显式栈

函数递归调用时，系统调用栈保存：

- 返回位置；
- 参数和局部状态；
- 当前调用尚未完成的信息。

把递归改写成迭代时，通常要自己建立栈并明确每个栈元素需要保存哪些状态。并不是简单地“把参数压进去”就完成了。

## 扩展：单调栈与单调队列

它们在普通栈、队列的基础上额外维护元素单调性，用于快速寻找“下一个更大元素”或滑动窗口极值。

这是高价值工程算法，但不是本章首次学习的必会主干。先确保基础操作和经典应用熟练，再进入该扩展。

## 方法选择表

| 场景 | 结构 | 原因 |
|---|---|---|
| 括号与嵌套 | 栈 | 最近未完成对象先处理 |
| 表达式运算符暂存 | 栈 | 等待更高优先级或右括号 |
| 回溯与递归状态 | 栈 | 后进入状态先恢复 |
| 任务按到达顺序处理 | 队列 | 先到先服务 |
| 树的层序遍历 | 队列 | 先发现的节点先扩展 |
| 图的广度优先搜索 | 队列 | 按距离层次推进 |
