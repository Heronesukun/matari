# 顺序表：用连续空间换随机访问

顺序表使用连续存储空间保存元素。其核心状态通常只有三部分：

```c
#define MAX_SIZE 100

typedef struct {
    int data[MAX_SIZE];
    int length;
} SeqList;
```

- `data`：存放元素；
- `length`：当前有效元素个数；
- `MAX_SIZE`：最大容量。

有效下标范围是 `0` 到 `length - 1`。

## 为什么随机访问是 `Θ(1)`

数组首地址已知，元素大小固定，第 `i` 个下标的位置可以直接由地址公式计算，不需要从头逐个经过前面的元素。

但按值查找仍通常要扫描，因此是 `Θ(n)`。**“数组查找是常数时间”只适用于按下标访问，不适用于任意按值查找。**

## 插入：先腾位置，再写入

约定在下标 `pos` 前插入元素 `x`，合法范围为 `0 <= pos <= length`。

```c
bool insert(SeqList *L, int pos, int x) {
    if (pos < 0 || pos > L->length) return false;
    if (L->length == MAX_SIZE) return false;

    for (int j = L->length; j > pos; j--) {
        L->data[j] = L->data[j - 1];
    }
    L->data[pos] = x;
    L->length++;
    return true;
}
```

### 为什么必须从后向前移动

假设 `[10, 20, 30, 40]` 要在下标 1 插入 15。

正确移动顺序：

```text
40 → 后一格
30 → 后一格
20 → 后一格
再写入 15
```

若从前向后移动，`20` 会先覆盖 `30`，后续再也拿不到原来的 `30`。

### 复杂度

- 尾部插入：若容量充足，`Θ(1)`；
- 头部插入：移动全部元素，`Θ(n)`；
- 一般最坏情况：`Θ(n)`。

## 删除：先保存，再向前覆盖

```c
bool erase(SeqList *L, int pos, int *removed) {
    if (pos < 0 || pos >= L->length) return false;

    *removed = L->data[pos];
    for (int j = pos; j < L->length - 1; j++) {
        L->data[j] = L->data[j + 1];
    }
    L->length--;
    return true;
}
```

删除时从前向后移动，因为目标是用后一个元素覆盖当前空位。

## 标例 1｜删除所有等于 `x` 的元素

要求原地完成，不使用另一个长度为 `n` 的数组。

稳定做法是维护“下一个保留位置” `k`：

```c
int remove_value(int a[], int n, int x) {
    int k = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] != x) {
            a[k] = a[i];
            k++;
        }
    }
    return k;
}
```

**识别：**题目要求原地删除多个元素，若每删一个就整体移动，最坏会到 `Θ(n^2)`。把所有保留元素一次性向前压缩，可以做到时间 `Θ(n)`、额外空间 `Θ(1)`。

**循环含义：**处理完下标 `0..i-1` 后，`a[0..k-1]` 恰好保存已经见过且需要保留的元素。

## 标例 2｜有序表合并

两个递增数组 `A`、`B` 合并到新数组 `C`：

```c
int i = 0, j = 0, k = 0;
while (i < m && j < n) {
    if (A[i] <= B[j]) C[k++] = A[i++];
    else C[k++] = B[j++];
}
while (i < m) C[k++] = A[i++];
while (j < n) C[k++] = B[j++];
```

每个元素只被读取和写入一次，时间 `Θ(m+n)`。

**识别信号：**两个序列都已有序，优先使用双指针，不要拼接后重新排序。

## 动态顺序表补充

实际工程中常使用动态数组：容量不足时申请更大空间并复制旧元素。它保留随机访问优势，但要区分：

- `length`：当前元素数；
- `capacity`：已分配可用槽位数。

尾插单次最坏可能因扩容达到 `Θ(n)`，但按倍数扩容时均摊为 `Θ(1)`。

## 高频易错点

- 把 `length` 当作最后一个有效下标；
- 插入位置范围漏掉 `pos == length` 的尾插；
- 插入从前往后移动导致覆盖；
- 删除后忘记 `length--`；
- 原地筛选时每次删除都移动，造成平方复杂度；
- 把按下标访问与按值查找混为一谈。

## 30 秒速查

```text
有效下标：0 ... length-1
插入位置：0 ... length
插入移动：从后向前
删除移动：从前向后
按下标访问：Θ(1)
中间插删：最坏 Θ(n)
批量删除：优先读写双指针
```
