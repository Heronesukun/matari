# 数据结构学习路线

数据结构研究的不是“容器名称”，而是：**怎样组织数据，才能让目标操作在可接受的代价内完成。**

同一组元素可以放在数组、链表、树或图中。真正决定选择的是操作需求：是否频繁随机访问、是否频繁在中间插入、是否要维护顺序、是否需要快速查找关系。

## 学习顺序

1. **复杂度**：先学会判断一个操作的代价，否则无法比较结构。
2. **线性表**：理解逻辑结构与存储结构的区别，掌握数组和链表的取舍。
3. **栈与队列**：学习“限制操作位置”如何换来稳定的行为模型。
4. **串、数组与矩阵**：把线性结构扩展到模式匹配和压缩存储。
5. **树与二叉树**：处理层次关系。
6. **图**：处理多对多关系和路径问题。
7. **查找**：围绕查找效率组织数据。
8. **排序**：比较不同数据移动与比较策略。

## MATARI 中的代码约定

示例使用接近 C 的伪代码，重点是结构和边界，不依赖某个编译器。默认约定：

- 数组下标从 `0` 开始；
- 线性表长度记为 `length`；
- 指针为空写作 `NULL`；
- 返回 `false` 表示操作条件不满足；
- 代码中的容量、头结点和循环队列约定会在页面开头明确说明。

不要直接背代码。先能用一句话说明循环不变量或指针含义，再去记实现。
