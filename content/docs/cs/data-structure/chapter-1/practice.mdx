# 复杂度精选练习

建议先在纸上写出“输入规模”和“基本操作次数”，再展开详解。只写最终 `O(...)` 不足以检查思路。

## A. 必会主干

### 1. 顺序循环

```c
for (int i = 0; i < 3 * n; i++) {
    x++;
}
```

求时间复杂度。

<details>
<summary>查看详解</summary>

**结论：**`Θ(n)`。

**识别：**循环次数为 `3n`，常数倍不改变渐近量级。

**过程：**循环体是常数时间操作，总执行次数为 `3n`，所以 `T(n)=3cn+c0`，保留主项得到 `Θ(n)`。

**复盘：**复杂度不是精确步数。`3n` 与 `n` 的增长速度相同。

</details>

### 2. 倍增循环

```c
for (int i = 1; i <= n; i *= 3) {
    x++;
}
```

<details>
<summary>查看详解</summary>

**结论：**`Θ(log n)`。

**识别：**循环变量每次乘 3。

**过程：**第 `k` 次后 `i=3^k`。循环结束需要 `3^k>n`，所以 `k` 与 `log_3 n` 同阶。对数底数只造成常数倍差异。

**复盘：**看到规模每次乘、除固定常数，优先想到对数。

</details>

### 3. 两段代码顺序执行

第一段为 `Θ(n log n)`，第二段为 `Θ(n^2)`，总复杂度是多少？

<details>
<summary>查看详解</summary>

**结论：**`Θ(n^2)`。

**识别：**顺序执行的总代价相加，再保留增长最快的项。

**过程：**`T(n)=Θ(n log n)+Θ(n^2)`。因为 `n^2` 比 `n log n` 增长更快，所以总量级为 `Θ(n^2)`。

**复盘：**不是把两个量级相乘。只有真正嵌套或每次外层都执行完整内层时才通常相乘。

</details>

### 4. 三角形循环

```c
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        x++;
    }
}
```

<details>
<summary>查看详解</summary>

**结论：**`Θ(n^2)`。

**识别：**内层次数依赖外层 `i`，要把每轮次数相加。

**过程：**总次数为 `1+2+...+n=n(n+1)/2`，最高项是 `n^2/2`，因此为 `Θ(n^2)`。

**复盘：**结果与规则双循环相同，但必须会解释三角形求和。

</details>

### 5. 辅助空间

```c
int sum(int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
```

辅助空间复杂度是多少？

<details>
<summary>查看详解</summary>

**结论：**`Θ(1)`。

**识别：**输入数组已经存在，不计入算法额外申请的空间。

**过程：**算法只使用 `s`、`i` 和参数等固定数量变量，不随 `n` 增长。

**复盘：**时间 `Θ(n)` 不代表空间也为 `Θ(n)`。

</details>

## B. 高频应用

### 6. 依赖外层的倍增循环

```c
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j *= 2) {
        x++;
    }
}
```

<details>
<summary>查看详解</summary>

**结论：**`Θ(n log n)`。

**识别：**第 `i` 轮内层执行 `Θ(log i)` 次，总次数为 `Σ log i`。

**过程：**上界为 `n log n`。同时后半段至少有 `n/2` 个 `i` 满足 `i≥n/2`，每个对应 `Θ(log n)` 次，因此下界也是 `Θ(n log n)`。

**复盘：**求和不必总写出精确公式，能给出同阶上下界即可。

</details>

### 7. 二分递归

```c
void f(int n) {
    if (n <= 1) return;
    f(n / 2);
}
```

时间和辅助空间复杂度分别是多少？

<details>
<summary>查看详解</summary>

**结论：**时间 `Θ(log n)`，辅助空间 `Θ(log n)`。

**识别：**每次只有一个递归分支，规模减半。

**过程：**递归链为 `n, n/2, n/4, ...`，直到 1，深度为 `Θ(log n)`。每层做常数工作；调用栈也保留同样多层。

**复盘：**不要因为出现递归就写指数级。关键看每层分支数和规模缩减方式。

</details>

### 8. 两分支递归

```c
void f(int n) {
    if (n <= 1) return;
    f(n / 2);
    f(n / 2);
}
```

<details>
<summary>查看详解</summary>

**结论：**时间 `Θ(n)`，递归栈辅助空间 `Θ(log n)`。

**识别：**递归树每层节点数翻倍，深度为 `log n`。

**过程：**第 `k` 层有 `2^k` 个调用，最后一层约有 `n` 个调用。整棵满二叉递归树节点总数与 `n` 同阶。虽然总调用数为 `Θ(n)`，但执行时只保留一条根到叶子的调用链，因此栈深度是 `Θ(log n)`。

**复盘：**时间看递归树总节点，栈空间看同时存在的最长路径。

</details>

### 9. 最好与最坏情况

顺序查找长度为 `n` 的数组，目标可能位于任意位置，也可能不存在。给出最好和最坏时间复杂度。

<details>
<summary>查看详解</summary>

**结论：**最好 `Θ(1)`，最坏 `Θ(n)`。

**识别：**算法会在找到目标时提前停止，因此操作次数依赖数据位置。

**过程：**目标在首元素时只比较一次；目标在末尾或不存在时需要比较 `n` 次。

**复盘：**平均情况还需要说明各位置和“不存在”的概率，题目没给分布时不要凭空计算。

</details>

### 10. 两个输入规模

```c
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        x++;
    }
}
```

<details>
<summary>查看详解</summary>

**结论：**`Θ(mn)`。

**识别：**这里有两个独立输入规模，不能擅自假设 `m=n`。

**过程：**外层执行 `m` 次，每次内层完整执行 `n` 次，总次数为 `mn`。

**复盘：**只有题目明确二者同阶时，才可进一步写成某个单变量量级。

</details>

## C. 补充辨识

### 11. 动态数组连续尾插

动态数组容量不足时按 2 倍扩容。连续执行 `n` 次尾插，单次最坏复杂度和均摊复杂度分别是什么？

<details>
<summary>查看详解</summary>

**结论：**单次最坏 `Θ(n)`，单次均摊 `Θ(1)`。

**识别：**扩容那一次要复制已有元素，但扩容不会每次发生。

**过程：**复制规模依次约为 `1,2,4,8,...`，总复制次数小于 `2n`，再加上 `n` 次写入，总成本仍为 `Θ(n)`。分摊到 `n` 次操作，每次为 `Θ(1)`。

**复盘：**均摊不是随机平均，而是对一段操作的确定总成本进行分摊。

</details>

### 12. 判断说法

“一个 `O(n)` 算法在所有输入上一定比 `O(n^2)` 算法快。”这句话是否正确？

<details>
<summary>查看详解</summary>

**结论：**不正确。

**识别：**渐近复杂度描述大规模输入下的增长趋势，不给出具体常数、实现和小规模表现。

**过程：**某个线性算法可能有很大的常数开销，而平方算法在很小的 `n` 上可能更快。但随着规模持续增大，较低增长量级通常会占优势。

**复盘：**复杂度用于规模趋势和可扩展性判断，不是每次运行时间的绝对比较。

</details>
