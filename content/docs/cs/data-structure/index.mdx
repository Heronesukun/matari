# 数据结构学习路线

数据结构研究的不是“容器名称”，而是：**怎样组织数据，才能让目标操作在可接受的代价内完成。**

第一次学习时，不应该同时承担“补 C 语言”和“理解结构”两种压力。因此课程现在先提供一个独立导入章节，再进入复杂度和具体结构。

## 第一次进入请先选路线

### 零基础或代码阅读不稳定

```text
导入章节
→ 复杂度
→ 线性表
→ 栈与队列
```

先完成 [导入 · 读懂数据结构代码](/docs/cs/data-structure/chapter-0)。你只需要达到“能手动执行和解释代码”的程度，不需要先学完完整 C 语言。

### 已经熟悉函数、数组和指针

直接做 [导入自测](/docs/cs/data-structure/chapter-0/readiness-check)。自测稳定后进入 [复杂度](/docs/cs/data-structure/chapter-1)。

## 学习顺序

0. **导入**：函数、控制流程、数组、结构体、指针、动态内存、递归与状态跟踪。
1. **复杂度**：先学会判断一个操作的代价，否则无法比较结构。
2. **线性表**：理解逻辑结构与存储结构的区别，掌握数组和链表的取舍。
3. **栈与队列**：学习“限制操作位置”如何换来稳定的行为模型。
4. **串、数组与矩阵**：把线性结构扩展到模式匹配和压缩存储。
5. **树与二叉树**：处理层次关系。
6. **图**：处理多对多关系和路径问题。
7. **查找**：围绕查找效率组织数据。
8. **排序**：比较不同数据移动与比较策略。

## 每章分两轮学习

**第一轮只建立主干：**知道对象、状态、基本操作和边界，完成 A 组必会题。

**第二轮再补完整性：**递归、均摊分析、特殊实现和 B/C 组练习可以在主干稳定后继续。

这意味着页面上出现的内容不是要求一次全部记住。第一次阅读时，应优先跟随每章开头的“首轮路线”。

## MATARI 中的代码约定

示例使用接近 C 的伪代码，重点是结构和边界，不依赖某个编译器。函数名、参数、指针和内存操作的统一说明放在 [导入章节](/docs/cs/data-structure/chapter-0)。

不要直接背代码。先能用一句话说明变量、循环不变量或指针含义，再去记实现。
