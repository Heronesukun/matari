# MATARI 操作系统课程大纲与创作验收规范

> 适用范围：`content/docs/cs/operating-system/` 下的路线页、章节页、练习页和实验页。
> 目标学习者：第一次系统学习操作系统，具备最小程序阅读与计算机组成基础的自学者。

## 1. 课程承诺

操作系统内容不能停留在“知道名词”。完成核心章节后，学习者应能：

1. 识别当前对象、资源与失败类型；
2. 用表、队列、寄存器、计数器或映射表示状态；
3. 根据系统调用、中断、调度、加锁、缺页和 I/O 完成等事件更新状态；
4. 选择合适的机制或策略，并说明条件、代价与不适用场景；
5. 检查安全性、活性、公平性、隔离性和持久化边界；
6. 把进程、调度、内存、I/O 与文件系统连接成完整执行路径。

只有定义、分类、算法名称或最终答案，不能算作完成。不得用“显然”“易得”“线程安全”跳过新的关键判断，也不得把只有目录的骨架页描述为完整章节。

## 2. 课程主线与学习层级

课程按四条轴组织：

- **虚拟化**：CPU、内存和设备如何呈现为多个独立环境；
- **并发**：多个执行流如何交错、同步并保持活性；
- **持久化**：数据如何组织、写入、恢复并跨重启保留；
- **保护**：谁能访问什么，故障和越权如何被限制在边界内。

章节是学习顺序，不是孤立知识盒。正文必须主动建立跨章连接。例如，一次 `read` 可能同时涉及系统调用、权限、阻塞、调度、页缓存、设备中断和文件系统元数据。

使用定性标签，不在没有统计语料时声称具体考试频率：

- **必会主干**：系统调用；进程线程；调度同步；死锁；分页与虚拟内存；设备与文件系统；保护与隔离。
- **高频应用**：`fork/exec/wait`；RR、SRTF、MLFQ；条件变量；银行家算法；多级页表；页面置换；inode 与日志恢复。
- **补充辨识**：多核与 NUMA、实时系统、SSD 与 RAID、虚拟机、容器、能力系统、容错和侧信道。

## 3. 前置学习合同

导入章只补进入正文所需的最小工具，不重讲完整 C 语言、汇编或计算机组成原理。学习者进入第一章前应能：

- 读懂变量、条件、循环、函数调用、指针和结构体字段；
- 用栈、队列、链表与位图表示简单状态；
- 认识 PC、通用寄存器、栈指针、主存、地址、指令和中断；
- 区分程序文本、运行状态与保存状态；
- 按事件序列更新状态表或时间线。

导入自测必须检验操作能力，并允许已掌握前置的学习者直接跳过。

## 4. 章节大纲与学习合同

| 章 | 主题 | 首轮完成能力 | 必须出现的标例或产出 |
| --- | --- | --- | --- |
| 0 | 导入：状态与执行路径 | 区分程序、进程、线程、用户态和内核态；读懂状态表与时间线 | 函数调用/系统调用；定时器中断；运行→阻塞→就绪 |
| 1 | 系统角色与系统调用 | 解释抽象、复用、隔离和受控服务；跟踪陷入与返回 | `open/read/write/close`；非法参数；机制与策略 |
| 2 | 进程、线程与切换 | 更新状态；解释 PCB/TCB；区分共享与私有资源 | `fork/exec/wait`；共享堆与私有栈；保存—选择—恢复 |
| 3 | 处理机调度 | 画时间线，计算等待、响应和周转时间；比较策略 | 同一任务集比较 FCFS、SRTF、RR；饥饿与老化 |
| 4 | 并发与同步 | 识别竞态；使用锁、信号量和条件变量 | `count++` 丢失更新；有界缓冲区；错误唤醒 |
| 5 | 死锁与活性 | 判断四条件；区分死锁、饥饿和活锁 | 反向加锁；资源分配图；安全性检查 |
| 6 | 地址空间与基本内存 | 区分虚拟/物理地址；处理分配、碎片和基础转换 | 基址/界限；动态分区；分段与分页 |
| 7 | 分页与虚拟内存 | 跟踪页表、TLB、缺页与置换；判断抖动 | 地址拆分；缺页事件链；FIFO/LRU/Clock |
| 8 | 设备与 I/O | 比较轮询、中断和 DMA；跟踪阻塞 I/O | 提交→阻塞→中断→唤醒；缓冲/缓存/假脱机；磁盘调度 |
| 9 | 文件系统与持久化 | 从路径解析到数据块定位；分析缓存与崩溃一致性 | fd/open-file/inode；索引容量；链接；日志恢复 |
| 10 | 保护、虚拟化与综合 | 解释访问控制和隔离；串联全课程机制 | `cat file`；写时复制；服务器；崩溃恢复；容器/虚拟机 |

每章应包含“开始前—核心页面—精选练习—可选实验”。核心页面和详解未完成前，不为填满导航创建空目录。

## 5. 页面结构

概念或机制页按以下顺序组织：

1. 本页目标；
2. 它解决什么问题；
3. 对象、状态和初始条件；
4. 什么时候想到它；
5. 核心机制与使用条件；
6. 状态变化流程；
7. 标准例与边界/失败例；
8. 机制或策略比较；
9. 易错点与跨章连接；
10. 小练习与速查。

每个核心方法必须回答：解决什么、看到什么信号、使用条件、实际步骤、替代方案为何更差、如何迁移。

算法比较页必须使用同一案例逐步对比，包含完整输入约定、至少两个评价维度、失败模式以及“首选/备选/不适用”规则，不能只列优缺点。

状态跟踪页必须明确初始状态、事件顺序、每步更新字段、不变量、终止条件、同分规则、单位和计时代价。长过程使用逐行表格，不把多步压成“按算法可得”。

实验页必须包含验证目标、环境与版本、安全可回滚操作、预期观察、结果与机制的对应、偏差诊断和迁移任务。首轮优先使用用户态工具、短程序或模拟器；内核修改放在第二轮。

## 6. 标例与练习规范

每个核心机制使用 2—4 个功能不同的例子：标准例、变形例、陷阱/边界例、跨章迁移例。每题必须先独立求解，并用第二种推导、状态守恒、小型模拟、实际运行或权威机制描述至少复核一次。

核心章节通常安排 8—15 题：

- A 必会主干：直接识别、状态跟踪和标准执行；
- B 高频应用：组合机制、策略比较、边界和故障诊断；
- C 补充辨识：少量设计、实验或扩展题。

每题详解至少包含：**结论、识别、初始状态、过程、检查、复盘**；改变条件会产生重要差异时加入**变式**。

## 7. 题目条件规范

| 题型 | 必须写明 |
| --- | --- |
| 调度 | 到达时刻、运行时间、优先级方向、抢占规则、时间片、同分规则、切换开销 |
| 并发 | 共享变量与初值、原子操作、锁/信号量初值、条件谓词、允许交错和唤醒语义 |
| 死锁 | 资源种类与实例数、当前分配、最大需求、请求向量和释放规则 |
| 地址转换 | 地址宽度、页大小、页表级数与项大小、有效位、权限位和 TLB 假设 |
| 页面置换 | 页框数、引用串、初始驻留页、全局/局部范围、脏页代价和并列规则 |
| I/O 与磁盘 | 设备模型、初始位置、移动方向、请求到达、距离或时间定义 |
| 文件系统 | 块与指针大小、索引结构、目录假设、缓存/同步语义和崩溃点 |

信息不足时，先指出缺失条件，再在显式假设下演示，不得默默补一个答案。

## 8. 表达、代码与图示规范

- 首次出现时定义术语，平台特定行为标注 POSIX、Linux、xv6 或 Windows；
- 区分程序/进程/线程，系统调用/异常/外部中断，虚拟页/物理页框；
- 区分等待/响应/周转时间，互斥/同步，死锁/饥饿/活锁；
- 区分缓冲/缓存/假脱机，fd/open-file/inode；
- 不把 TLB miss、缺页和 cache miss 混为一谈；
- 不把 `write` 返回写成数据已持久落盘，除非条件明确保证。

首轮使用接近 C/POSIX 的伪代码并明确标注；真代码检查系统调用返回值；并发代码声明共享变量、初值、原子操作、锁保护范围和唤醒语义。默认只提供非破坏性、无需管理员权限的命令，并给出清理步骤。

图示优先使用状态转移表、时间线、地址字段、资源矩阵、ASCII 块映射和事件序列表。每个箭头说明触发事件，每张表说明行列含义。

## 9. 来源与原创性

课程范围交叉校验 ACM/IEEE-CS/AAAI *Computer Science Curricula 2023*、*Operating Systems: Three Easy Pieces*、MIT 6.1810 与 xv6；说明接口或具体实现时使用相应官方规范、手册和源码。

来源用于核对定义、边界、接口和范围，不复制教材段落或题解。标例优先原创；改编真实题目时说明来源与改动；不把生成题称为真题；没有定义语料和统计方法时不写百分比或“每年必考”。

## 10. 完成与发布验收

章节只有同时满足以下条件才可标记为完整：

- 路线页说明目标、前置、首轮和第二轮；
- 每个核心机制完成“问题—信号—条件—状态—流程—比较—迁移”；
- 每个核心机制有 2—4 个功能不同的标例，至少一个展示失败或边界；
- 练习按 A/B/C 分层，共 8—15 题，且都有详细解答；
- 时间线、地址翻译、并发过程和计算已独立复核；
- 平台特定内容已标注，导航与链接正确；
- `npm run check:content` 与 `npm run build` 通过；
- GitHub 回读正确，Vercel 生产部署为 `READY`，实际页面无原始 MDX、损坏字符或导航错误。

质量评分每项 0—2 分：正确性、自学闭环、状态跟踪、方法选择、标例、练习、精简递进、跨章迁移、渲染导航。核心页面要求正确性和渲染均为 2，总分至少 14/18。

## 11. 建设顺序

按导入、系统边界、进程线程、调度、同步、死锁、内存、虚拟内存、I/O、文件系统、保护与综合的顺序建设。每次提交完成一个连贯学习目标，同时包含必要导航、练习和详解；不得先创建一批空标题页，再把“目录完整”当作课程完成。
