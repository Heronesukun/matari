# 线性表：先分清逻辑与存储

线性表是一组具有先后关系的元素：除首尾外，每个元素都有唯一前驱和后继。

这句话描述的是**逻辑结构**，没有规定元素在内存中必须连续。实现线性表时，最常见的两种存储方式是：

- **顺序表**：元素放在连续存储空间中，用下标定位；
- **链表**：节点通过指针连接，物理位置可以分散。

## 先记住选择核心

```text
频繁按位置访问 → 顺序表更自然
频繁在已知节点附近插入删除 → 链表更自然
```

但不要把它背成绝对结论。链表若要先查找第 `i` 个位置，查找本身仍要 `Θ(n)`；顺序表在尾部插入且容量充足时也可以是 `Θ(1)`。

## 线性表的基本操作

无论底层怎样实现，通常都关心：

- 初始化与销毁；
- 判空、求长度；
- 按位置取元素；
- 按值查找；
- 在第 `i` 个位置插入；
- 删除第 `i` 个元素；
- 遍历与修改。

学习时要把“抽象操作”和“具体实现”分开：同一个 `insert(i, x)`，在顺序表中意味着移动元素，在链表中意味着改指针。

## 一道题的通用判断顺序

1. 题目主要需要随机访问还是局部修改？
2. 元素数量是否有稳定上限？
3. 插入删除位置是否已经拿到节点指针？
4. 是否要求存储紧凑、缓存友好？
5. 是否能接受每个节点额外的指针空间？
