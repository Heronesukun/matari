# 计算机基础

计算机课程最容易出现两种低效学习方式：一种只背名词，知道“栈是后进先出”却不会执行操作；另一种一开始就陷入大量语法和硬件细节，看完以后仍不知道题目在考什么。

MATARI 采用分层路线：

```text
导入前置
→ 第一轮建立主干
→ A 组练习确认可用
→ 第二轮补扩展
→ B / C 组完成迁移
```

## 第一步不是立刻进入正文

根据课程选择导入：

- [数据结构导入](/docs/cs/data-structure/chapter-0)：解决代码函数、数组、指针、动态内存、递归和取模的阅读障碍；
- [计算机组成原理导入](/docs/cs/computer-organization/chapter-0)：解决位编号、位权、固定宽度、逻辑运算和移位的阅读障碍。

导入章节只补“进入正文所需的最低基础”，不会把一门编程语言或数字逻辑课程完整塞进前置部分。

## 阅读正文时关注五件事

1. **对象是什么**：数据、节点、位模式、寄存器还是指令。
2. **状态怎么表示**：哪些变量共同描述当前状态。
3. **操作如何改变状态**：一次插入、出栈、移位或加法到底改变了什么。
4. **约束在哪里**：容量、边界、编码位宽、溢出条件、前置条件。
5. **代价是什么**：时间、空间、硬件复杂度或精度损失。

## 当前学习入口

- [数据结构](/docs/cs/data-structure)：导入后依次学习复杂度、线性表、栈与队列。
- [计算机组成原理](/docs/cs/computer-organization)：导入后先学习数据表示与运算，再连接存储和 CPU。

## 推荐自学动作

每看完一个标例，先不要继续向下滚动。尝试自己回答：

- 我为什么选择这个结构或方法？
- 当前状态由哪些量表示？
- 边界条件是什么？
- 若输入规模、位宽或操作顺序改变，结论会不会变？

如果只能复述定义，却无法手动执行一次操作流程，就回到本章“开始前”页面或导入章节补对应前置。
