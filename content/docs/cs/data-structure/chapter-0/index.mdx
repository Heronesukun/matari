# 导入：第一次怎样读数据结构代码

这一章不是一门缩小版的 C 语言课程。它只解决一个问题：**当正文出现一段代码时，你能看懂输入是什么、状态改了哪里、函数最后返回什么。**

数据结构学习最容易卡住的地方，往往不是结构本身，而是同时遇到了数组、函数、指针和内存分配。把这些前置内容单独放在这里，后面的章节就可以把注意力集中在结构和算法上。

## 先选一条路线

1. [函数与控制流程](/docs/cs/data-structure/chapter-0/functions-and-control)

## MATARI 的代码是什么性质

正文使用**接近 C 的伪代码**：

- 语法尽量符合 C 的阅读习惯；
- 会省略与知识点无关的头文件、错误输出和工程封装；
- `visit`、`swap`、`push` 等名字有时表示抽象操作，不一定是语言自带函数；
- 每一页会说明关键变量和边界约定。

因此，学习目标不是“复制后立刻编译”，而是能回答：

```text
这个函数接收什么？
哪些变量描述当前状态？
每一步改变了什么？
什么时候停止？
失败时返回什么？
```

> 看不懂某个函数名时，先寻找它的输入、输出和副作用，不要先猜它属于哪个库。

从 [函数与控制流程](/docs/cs/data-structure/chapter-0/functions-and-control) 开始。
