# 第二章 · 一元函数微分学

这一章要建立两个能力：

1. **算得出导数**：复合、隐函数、参数方程、高阶导数不慌。
2. **会用导数判断问题**：单调、极值、凹凸、渐近线、证明题。

> 学习标准：不要把“求导”和“导数应用”分成两门课。求导是工具，后面的性质分析才是它最常见的用途。

## 必会主干

- 导数定义、左右导数、可导与连续的关系。
- 基本求导公式与四则运算。
- 复合函数、隐函数、参数方程求导。
- 高阶导数与微分。
- 罗尔、拉格朗日、柯西中值定理的使用条件。
- 洛必达法则。
- 单调、极值、最值、凹凸、拐点、渐近线。

## 高频应用

- 分段函数在分界点的可导性。
- 含参数函数用连续/可导条件确定参数。
- 中值定理证明等式、不等式或根的唯一性。
- 洛必达与泰勒求复杂极限。
- 导数符号表分析函数性质。
- 最值建模问题。

## 补充辨识

- 反函数求导会用公式即可，不单独深挖。
- 曲率、曲率半径按大纲保留基本公式和识别，优先级低于单调/极值/凹凸。
- 复杂高阶导数公式只保留常见结构，不做炫技型计算。
