# 导入：第一次怎样阅读位模式

计算机组成原理的困难常常不是计算，而是同一页同时出现了二进制、位宽、编码、逻辑运算和硬件名词。这个导入章节先把阅读工具补齐，正文再讨论补码、浮点数和 ALU。

这一章不是数字电路完整课程，也不会提前讲完数据表示。它只要求你能：

```text
看清一共有多少位
分清最高位与最低位
按位权读取一个无符号模式
执行简单的 AND / OR / XOR / NOT
理解左移、右移和固定位宽截断
```

## 一个贯穿后续章节的习惯

任何二进制结论前，先写两项：

```text
位宽：8 位 / 16 位 / 32 位 ...
解释规则：无符号 / 补码 / 浮点字段 / 字符编码 ...
```

例如 `11111111`：

- 作为 8 位无符号数是 255；
- 作为 8 位补码整数是 -1；
- 作为某条指令中的字段，可能根本不是一个完整数值。

位模式没有自行携带类型。类型来自使用它的指令和上下文。
