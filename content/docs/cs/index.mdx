# 计算机基础

计算机课程最容易出现两种低效学习方式：一种只背名词，知道“栈是后进先出”却不会写操作；另一种一开始就陷入大量实现细节，看完以后仍不知道题目在考什么。

MATARI 采用中间路线：**先建立可执行的模型，再补足解释模型所需的原理。**

## 阅读一页时关注五件事

1. **对象是什么**：数据、节点、位模式、寄存器还是指令。
2. **状态怎么表示**：哪些变量共同描述当前状态。
3. **操作如何改变状态**：一次插入、出栈、移位或加法到底改变了什么。
4. **约束在哪里**：容量、边界、编码位宽、溢出条件、前置条件。
5. **代价是什么**：时间、空间、硬件复杂度或精度损失。

## 当前学习入口

- [数据结构](/docs/cs/data-structure)：先学习复杂度，再进入线性表、栈与队列。
- [计算机组成原理](/docs/cs/computer-organization)：先学习数据在机器中的表示，再理解运算部件如何处理这些位。

## 推荐自学动作

每看完一个标例，先不要继续向下滚动。尝试自己回答：

- 我为什么选择这个结构或方法？
- 当前状态由哪些量表示？
- 边界条件是什么？
- 若输入规模、位宽或操作顺序改变，结论会不会变？

如果只能复述定义，却无法手动执行一次操作流程，就还没有真正掌握。
