# 开始前：复杂度需要哪些代码基础

复杂度分析不是考 C 语法，但你需要能看出代码重复了多少次。第一次学习前，先确认下面四件事。

## 最低前置检查

你应该能够解释：

```c
for (int i = 0; i < n; i++) {
    visit(a[i]);
}
```

- `i` 从哪里开始；
- 每轮怎样变化；
- 什么时候停止；
- `visit` 总共执行多少次。

还需要认识：

```c
return f(n / 2);
```

表示函数用更小的输入再次调用自己。现阶段只需能画出调用规模 `n, n/2, n/4, ...`，不要求先会递推公式。

若这些还不稳定，先看：

- [函数与控制流程](/docs/cs/data-structure/chapter-0/functions-and-control)
- [状态跟踪、递归与取模](/docs/cs/data-structure/chapter-0/trace-recursion-modulo)

## 第一次只学主干

复杂度正文信息较多，建议分两轮。

### 第一轮

1. 理解复杂度比较的是增长速度，不是具体秒数；
2. 掌握“定规模 → 找基本操作 → 算次数 → 取主项”；
3. 看懂单循环、倍增循环和三角形循环；
4. 区分时间与辅助空间；
5. 完成 [复杂度精选练习](/docs/cs/data-structure/chapter-1/practice) 的 A 组 1—5 题。

第一轮暂时不需要熟练掌握：

- `O`、`Θ`、`Ω` 的严格区别；
- 多分支递归树；
- 平均情况的概率模型；
- 均摊复杂度。

### 第二轮

主干稳定后，再回到正文补递归、最好/最坏/平均情况与均摊分析，并完成 B、C 组练习。

## 本章会出现的名字

| 名称 | 含义 |
|---|---|
| `n` | 输入规模，具体可能是数组长度、节点数或其他数量 |
| `visit(x)` | 对元素做一次常数时间处理的占位操作 |
| `T(n)` | 输入规模为 `n` 时的操作次数或时间函数 |
| `Θ(g(n))` | 增长量级与 `g(n)` 同阶 |
| 辅助空间 | 除输入本身以外，算法额外使用的空间 |

## 两个热身问题

### 热身 1

```c
for (int i = 0; i < 2 * n; i++) count++;
```

循环次数是 `2n`。虽然精确次数有常数 2，但增长量级仍与 `n` 同阶。

### 热身 2

```c
for (int i = 1; i <= n; i *= 2) count++;
```

`i` 依次翻倍。不要直接套双循环经验，而要写出 `1, 2, 4, 8, ...`。

能解释这两个例子后，进入 [复杂度正文](/docs/cs/data-structure/chapter-1)。
